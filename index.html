Logic ที่แก้แล้ว: MTA คือ “ฝั่งที่รับข่าวจากเรา” / ALTN คือ “ทางสำรองของ MTA นั้น”

ค้นด้วย Routing เช่น B, UG, WBA, WB, VV เพื่อดูว่าเราควรส่ง/ประสานหลักกับใคร และสำรองคือใคร

ระบบใช้การค้นหาแบบ prefix: เช่น B จะ match Route B, แต่ถ้าพิมพ์ WBA จะไป match WBA โดยไม่ตกไป WB (Except WBA, WBS)

วิธีอ่านผล

หลัก / Main MTA = ฝั่งที่เราส่ง Routing นั้นไปหา หรือฝั่งที่รับข่าวจากเรา
ALTN = เส้นทางสำรองของ Main MTA นั้น กรณี main route ใช้งานไม่ได้
Except = ห้ามเหมารวม เช่น WB (Except WBA, WBS) หมายถึง WB ทั่วไปไป VVTS แต่ WBA/WBS ต้องไปตาม record ที่ระบุแยก
